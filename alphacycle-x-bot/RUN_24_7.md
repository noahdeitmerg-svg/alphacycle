# AlphaCycle X Bot — 24/7 Betrieb (nur Telegram bestätigt X-Posts)

## So funktioniert es

| Läuft automatisch (ohne dich) | Nur mit deiner Aktion |
|------------------------------|------------------------|
| Tweets scannen | |
| ARC-Kontext holen | |
| Reply-Text mit Claude erzeugen | |
| Eintrag in `pending_replies` + **Telegram-Nachricht** mit POST/SKIP | |
| | Du tippst **POST** oder **SKIP** in Telegram |
| Nach POST: Bot postet den Reply auf X | |

**Du musst nichts am Rechner klicken** — nur in Telegram auf **POST** oder **SKIP**, wenn eine Kandidaten-Nachricht kommt.

## Zwei Prozesse (beide nötig)

1. **`python3 bot.py`** — Scan-Zyklen, Generierung, Telegram-Versand  
2. **`python3 telegram_listener.py`** — wartet auf deine Button-Klicks und ruft dann `poster.post_reply` bzw. Skip auf

Ohne (2) kannst du in Telegram zwar Nachrichten sehen, aber **POST** tut nichts zuverlässig.

## `.env` (VPS)

Pflicht u. a.:

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (z. B. `1388464985`)
- Alle Twitter- und Claude-Keys wie bisher

`config.py` lädt `.env` automatisch aus dem Ordner neben `config.py`.

### API-Credits schonen (Standard)

- **Scan alle 30 Minuten:** Standard ist `SCAN_INTERVAL_SECONDS=1800` (in `.env` überschreibbar).
- Weniger Reads = weniger Kosten als z. B. alle 5 Minuten.

### Telegram nur testen (ohne echten Tweet)

Auf dem Server, Listener muss laufen (`telegram_listener.py`):

```bash
cd ~/alphacycle-repo/alphacycle-x-bot
python3 test_telegram_approval.py
```

In Telegram **nur SKIP** tippen (POST ist absichtlich ungültig für diesen Test).

### SSH vom Windows-PC (PowerShell + Passwort)

Im Repo: `ssh-from-windows.ps1` — IP eintragen, ausführen, Passwort eingeben wenn `ssh` fragt.  
Oder manuell: `ssh root@DEINE_IP`

## Option A: `screen` (einfach)

```bash
cd /pfad/zu/alphacycle-x-bot
screen -S xbot -dm bash -lc 'exec python3 bot.py'
screen -S tg  -dm bash -lc 'exec python3 telegram_listener.py'
screen -ls
```

Logs: `screen -r xbot` bzw. `screen -r tg` (Detach: `Ctrl+A`, dann `D`).

## Option B: `systemd` (empfohlen für 24/7 + Neustart)

Siehe Ordner `systemd/`: Units kopieren, **`WorkingDirectory`** auf deinen echten Pfad setzen, dann:

```bash
sudo cp systemd/alphacycle-x-bot.service /etc/systemd/system/
sudo cp systemd/alphacycle-x-bot-telegram.service /etc/systemd/system/
sudo nano /etc/systemd/system/alphacycle-x-bot.service   # WorkingDirectory anpassen
sudo nano /etc/systemd/system/alphacycle-x-bot-telegram.service
sudo systemctl daemon-reload
sudo systemctl enable --now alphacycle-x-bot.service
sudo systemctl enable --now alphacycle-x-bot-telegram.service
sudo systemctl status alphacycle-x-bot.service alphacycle-x-bot-telegram.service
```

Logs:

```bash
journalctl -u alphacycle-x-bot.service -f
journalctl -u alphacycle-x-bot-telegram.service -f
```
